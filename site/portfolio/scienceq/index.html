ScienceQ (demo)

Python · LangChain and LangGraph · Cohere multilingual embeddings and Rerank · Pinecone · gpt-oss-120b via Groq · FastAPI · React · Google Cloud Run

What this project shows

  • Answers grounded in sources. An answer cites the videos it came from as clickable timestamps, so a reader can check it.
  • One search across five languages. Transcripts in all five share one multilingual embedding space, searched with one index.
  • It says when it does not know. If nothing relevant clears a confidence threshold, the assistant says so instead of inventing an answer.
  • It discloses that it is an AI, as Art. 50(1) of the EU AI Act requires: before the first question, on every answer, and when a user asks whether they are talking to a bot.

How it works

ScienceQ answers questions about a corpus of 50 science explainer videos in English, Spanish, German, French and Portuguese, from channels such as Veritasium, Kurzgesagt, 3Blue1Brown and Terra X Lesch. A user can also paste a YouTube link, and the video is ingested on the spot and becomes searchable.

Retrieval runs in two stages. A vector search in Pinecone returns the ten closest transcript passages, a reranker narrows them to the best three, and only those three reach the language model. Answers stream token by token, and each carries its sources as clickable timestamps. Follow-up questions are rewritten against the last five turns, so "and why is that?" is searched as a full question.

The question about being a bot is answered by a fixed rule rather than by the model, so the answer is honest every time. The disclosure obligations, and what would trigger new ones, are tracked in the repository's compliance document.

Answer quality was scored against a set of test questions for correctness, grounding, conciseness and tone. The repository reports the scores with their limits: the test set grew after the best-scoring run, and that run cannot be reproduced.

It started as the final project of the Ironhack AI Engineering course, and I have taken it further since: search across five languages, reranking with Cohere, and the EU AI Act disclosure safeguards. It runs on Google Cloud Run. Try it at scienceq.app, or read the code on GitHub.
